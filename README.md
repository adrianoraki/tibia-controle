# TibiaControle

Site para jogadores de Tibia controlarem hunts, metas, loot para NPC, compras no Market e gastos.
Cada usuário tem login próprio e só enxerga os próprios dados (Row Level Security do Supabase).

- Front-end: HTML, CSS e JavaScript puro (sem build)
- Banco e login: Supabase (projeto `TibiaControle`)
- Hospedagem: Vercel

Preços de NPC: TibiaWiki. Tibia é marca registrada da CipSoft GmbH; este é um site de fã.
